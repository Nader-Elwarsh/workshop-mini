# نظام الورشة المصغر V5 — الأربع وحدات المترابطة

## الوحدات
1. العملاء
2. الأجهزة
3. أوامر الشغل / طلبات الصيانة
4. المخزن

## الربط
العميل هو الأصل: عميل ← عنوان ← جهاز ← أمر شغل ← قطع غيار ← حركة مخزن.

كل وحدة مستقلة في شاشة وقائمة وملف 360°، لكن يمكن الانتقال من أي ملف إلى الكيانات المرتبطة به.

## تحسينات معتمدة
- العميل: اسم، تليفون، عنوان، منطقة مطاي/بني مزار، قرى مطاي كاملة، مواعيد مناسبة للزيارة، عناوين إضافية.
- لا توجد خانة ملاحظات عامة للعميل.
- الجهاز لا يحتوي رقمًا مسلسلًا.
- الجهاز لا يمكن حفظه بدون عميل وعنوان.
- نوع الجهاز وتصنيفه منفصلان؛ الغسالة: هاف أوتوماتيك / فوق أوتوماتيك / أمامي أوتوماتيك.
- الماركة قائمة اختيارات تشمل العلامات الشائعة في مصر وصعيد مصر مع خيار أخرى.
- أمر الشغل لا يحتوي خانة فني.
- أمر الشغل مرتبط بالعميل والجهاز والعنوان.
- حالات وأولوية وموعد زيارة وكشف وأعمال ورسوم زيارة وإصلاح ومدفوع ومتَبقي وضمان.
- تاريخ نهاية الضمان للتذكير.
- الفاتورة القانونية النهائية منفصلة عن الكشف/التقدير المبدئي.
- قطع الغيار مرتبطة بأمر الشغل وتُخصم من المخزن عند الحفظ، مع تسوية الفرق عند التعديل.
- حركة مخزن يدوية للدخول والخروج.
- بحث فوري في العملاء والأجهزة وأوامر الشغل والمخزن.
- سجل عمليات مختصر في التخزين المحلي.
- تنبيهات للضمان والمخزون المنخفض/النافد.
- حفظ العميل/الجهاز/أمر الشغل/القطعة يفتح الملف 360° مباشرة.
- ترحيل تلقائي لبيانات V4 القديمة إن وجدت.

## القرى
تم إدراج قائمة قرى مركز مطاي وفق المصادر المتاحة، مع إبقاء العنوان التفصيلي مفتوحًا لأي عزبة أو نجع أو عنوان غير موجود بالقائمة.

## التشغيل الحالي
هذه نسخة ويب مستقلة تعتمد على LocalStorage داخل نفس المتصفح. عند الانتقال لاحقًا لقاعدة بيانات حقيقية، تظل نفس العلاقات والمنطق هي الأساس.
