# نظام الورشة المصغر V4 — أربع وحدات مترابطة

الوحدات الأربع مستقلة في الواجهة ومترابطة في البيانات:
1. العملاء
2. الأجهزة
3. طلبات الصيانة
4. المخزن

العلاقات:
العميل ← عناوينه ← أجهزته ← طلبات صيانته ← قطع الغيار ← حركات المخزن.

القرارات المعتمدة:
- العميل: اسم، تليفون، عنوان.
- مطاي وبني مزار؛ قرى مطاي فقط، وبني مزار عنوان يدوي.
- لا ملاحظات للعميل.
- الجهاز بلا رقم مسلسل.
- طلب الصيانة بلا فني.
- الضمان بتاريخ نهاية.
- الحفظ يفتح ملف 360° لكل كيان.
- تعدد عناوين العميل مدعوم، والجهاز والطلب مرتبطان بعنوان.
- البحث والفلاتر، الأولويات، حالات الطلب، التكلفة والمدفوع والمتبقي.
- التنبيه/التقدير المبدئي ليس فاتورة قانونية.
- الفاتورة القانونية النهائية بعد اكتمال الطلب.
- المخزن يدعم الحد الأدنى وسجل الحركة المرتبط بطلب الصيانة.
- سجل عمليات محلي.
- تصميم Mobile First.
- الصور مدعومة للأجهزة وقطع الغيار.

- طلب الصيانة يسمح باختيار قطع غيار من المخزن؛ الحفظ يخصم الكمية ويسجل حركة خروج مرتبطة بالطلب، وتعديل الطلب يعالج فرق الكمية.
- ملف القطعة يسمح بحركات مخزون يدوية للدخول والخروج.
