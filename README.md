# الورشة الفنية — Workshop Mini

نظام إدارة مصغر لورشة صيانة أجهزة منزلية، شغال كـ PWA (تطبيق ويب قابل للتثبيت) من غير أي Backend — كل البيانات محفوظة محليًا على نفس الجهاز/المتصفح (localStorage).

## الأقسام
- 👥 العملاء وعناوينهم
- 🔧 الأجهزة المرتبطة بكل عميل
- 🛠️ أوامر الشغل (الحالة، الحسابات، قطع الغيار، الصور)
- 📦 المخزن وقطع الغيار
- 💰 الخزنة (درج نقدي مستقل عن حسابات أوامر الشغل)
- ✅ المهام والمتابعة
- 🗺️ خط السير (اليوم + القادم)، مجمّع حسب المركز والقرية
- 📊 التقارير والتحليلات

## التشغيل
افتح `index.html` في المتصفح، أو ثبّت التطبيق على الهاتف (PWA) لاستخدامه أوفلاين بعد أول تحميل.

## ملاحظة أمنية مهمة
البيانات محفوظة في `localStorage` على نفس الجهاز/المتصفح فقط — لا يوجد مزامنة سحابية ولا صلاحيات مستخدمين حقيقية. مناسب للاستخدام الفردي/التجريبي؛ أي استخدام إنتاجي حقيقي متعدد المستخدمين يحتاج Backend.

## البنية
- `app.js` + `app-core` منطقيًا مدموجين في `app.js` — منطق الأقسام الأساسية.
- `workshop-mini-simple-ui.js` — واجهة الملخصات المبسطة (الشاشة الرئيسية، أوامر الشغل، خط السير القادم).
- `workshop-mini-enhancements.js` — تحسينات العملاء والأجهزة (بحث، حذف آمن، ملف 360°).
- `reports.js` — صفحة التقارير.
- `print-share.js` / `print-share.css` — أزرار الطباعة/المشاركة في سياقات محددة.
- `notif-shared.js` + `service-worker.js` — التخزين الأوفلاين والإشعارات.
- `style.css` — التنسيق العام لكل الصفحات.
