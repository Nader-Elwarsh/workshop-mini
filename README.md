# الورشة الفنية — نسخة إصلاح قطع الغيار وترتيب القرى

- إصلاح إضافة قطع الغيار من داخل ملف أمر الشغل.
- زر تأكيد إضافة القطعة يتحقق من القطعة والكمية ويحفظ الحركة ويحدث الحساب والمخزن.
- إصلاح مسار إضافة القطع أثناء تعديل أمر الشغل.
- إضافة ترتيب القرى داخل كل مركز بأزرار ↑ ↓ مع حفظ الترتيب.
- لا يتم حذف أي من وظائف النظام السابقة.
