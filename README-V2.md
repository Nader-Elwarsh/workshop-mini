# Workshop Mini V2 — Focused Enhancements

هذه الحزمة تعدل النسخة المصغرة الحالية فقط، بدون إضافة أقسام جديدة.

## الملفات التي يتم استبدالها
- customers.html
- customer.html
- devices.html
- device.html

## الملف الجديد
- workshop-mini-enhancements.js

اترك باقي ملفات المشروع كما هي.

## ما تم تحسينه
- بحث العملاء: الاسم، الهاتف، العنوانين والبيانات المتاحة.
- ملف العميل 360°: ملخص أوضح + الأجهزة + أوامر الشغل المرتبطة.
- حذف العميل: لم يعد ممنوعًا؛ يظهر تحذير وتأكيد، ثم يحذف العميل وما يرتبط به ويعيد قطع الغيار للمخزن.
- حذف الجهاز: لم يعد ممنوعًا؛ يظهر تحذير وتأكيد، ثم يحذف الجهاز وأوامر الشغل المرتبطة به ويعيد قطع الغيار للمخزن.
- بحث الأجهزة: يشمل العميل والنوع والتصنيف والماركة والموديل والوصف.
- إصلاح helper مفقود خاص باكتشاف رقم هاتف العميل المكرر مع إبقاء قرار إنشاء العميل للمستخدم.
- لا توجد إضافات تخص الفنيين أو Backend أو الولاء أو الإشعارات أو أي قسم جديد.
