# الورشة الفنية — نظام إدارة الورشة المصغر (V11.2.6)

تطبيق ويب (PWA) لإدارة ورشة صيانة الأجهزة المنزلية: العملاء، الأجهزة،
أوامر الشغل، والمخزن. يعمل بالكامل من المتصفح ويخزن البيانات محليًا.

## الأقسام
- 👤 العملاء — بيانات العميل، عنوانين (أساسي وإضافي)، بحث شامل، حذف مع تحذير.
- 🔧 الأجهزة — نوع/تصنيف/ماركة/موديل/صورة، مرتبطة بعميل، حذف مع تحذير.
- 🛠️ أوامر الشغل — الحالة، الأولوية، مكان التنفيذ، متابعة الورشة، قطع الغيار
  المستخدمة، الحساب (مصنعية + قطع − عربون)، إغلاق نهائي بعد الدفع الكامل.
  مجلدات سريعة: مكتملة، أوامر الورشة، أوامر اليوم، انتظار قطع غيار، متأخرة.
- 📦 المخزن — القطع، الكمية، الحد الأدنى للتنبيه، سعر الشراء/الاستخدام،
  سجل الحركات (خروج/إرجاع) لكل قطعة.
- ⚙️ الإعدادات — تعديل قوائم النظام (المراكز، القرى، الأنواع، التصنيفات،
  الماركات، الحالات...) بالسحب والإفلات أو برقم ترتيب، وحذف جماعي للبيانات
  التشغيلية عند الحاجة.

## هيكل الملفات
```
index.html        الصفحة الرئيسية ولوحة التحكم
customers.html / customer.html    قائمة العملاء / ملف عميل 360°
devices.html   / device.html      قائمة الأجهزة  / ملف جهاز 360°
requests.html  / request.html     قائمة أوامر الشغل / ملف أمر شغل 360°
inventory.html / part.html        المخزن / ملف قطعة غيار
settings.html                      إعدادات قوائم النظام
app.js          كل منطق التطبيق (البيانات، الصفحات، PWA)
style.css       التنسيق
service-worker.js / manifest.json  دعم PWA (تثبيت + عمل Offline)
```

كل الصفحات تحمّل `app.js` فقط — هو الملف الوحيد المسؤول عن منطق النظام.

## التخزين
البيانات محفوظة في `localStorage` على نفس المتصفح/الجهاز تحت مفاتيح مختصرة
(`wf_c` عملاء، `wf_d` أجهزة، `wf_r` أوامر شغل، `wf_p` قطع غيار، `wf_s` إعدادات،
`wf_m` حركات مخزن). **لا توجد مزامنة سحابية بين الأجهزة** في هذه النسخة —
كل جهاز/متصفح له بياناته الخاصة.

## PWA (تثبيت وعمل بدون إنترنت)
- `manifest.json` يسمح بتثبيت التطبيق على الهاتف كأيقونة مستقلة.
- `service-worker.js` يخزّن الملفات الأساسية مؤقتًا (Cache) بعد أول تحميل
  ناجح، فيعمل التطبيق بدون إنترنت لاحقًا. عند توفر الإنترنت يجلب أحدث نسخة
  من الملفات تلقائيًا (Network-first) دون المساس ببيانات `localStorage`.
- زر "📲 تثبيت التطبيق" يظهر تلقائيًا عندما يسمح المتصفح بذلك.
- صفحات الملف الشخصي (`customer.html?id=...` وغيرها) تُخزَّن في الكاش حسب
  المسار بدون اعتبار الـ query string، حتى تفتح بشكل صحيح أوفلاين.

## ملاحظات مهمة
- صور الأجهزة/القطع تُخزَّن كـ Data URL داخل `localStorage` نفسه (لا يوجد
  تخزين سحابي للصور). لو ظهرت رسالة امتلاء المساحة، جرّب صورة أصغر أو احذف
  صورة قديمة.
- حذف عميل أو جهاز مسموح به، ويظهر تحذير واضح قبل التنفيذ، ويحذف تلقائيًا
  أوامر الشغل المرتبطة ويعيد قطع الغيار المصروفة للمخزن.
- أمر الشغل بعد "تم الدفع بالكامل وإغلاق الأمر" يُقفل نهائيًا ولا يمكن تعديله
  أو حذفه من الحذف الفردي (فقط عبر الحذف الجماعي من الإعدادات عند الحاجة).
