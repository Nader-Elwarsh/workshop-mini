# نظام الورشة الفنية — نسخة ترتيب الإعدادات بالسحب والإفلات

هذه النسخة مبنية على النسخة المعتمدة السابقة.

## الجديد
- ترتيب المراكز بالسحب والإفلات.
- ترتيب القرى داخل كل مركز بالسحب والإفلات.
- ترتيب أنواع الأجهزة بالسحب والإفلات.
- ترتيب الماركات بالسحب والإفلات.
- ترتيب تصنيفات المخزن بالسحب والإفلات.
- ترتيب كل قوائم الإعدادات الديناميكية بالسحب والإفلات.
- ما زال رقم الترتيب المباشر متاحًا كطريقة بديلة.
- أزرار التعديل والحذف باقية.
- السحب مدعوم بالماوس، مع دعم لمس الهاتف عبر مقبض ☷.
- الترتيب يُحفظ في إعدادات النظام وينعكس على قوائم الاختيار المرتبطة.
