# نظام الورشة المصغر
نسخة بداية مستقلة عن المشروع القديم.

الوحدات: العملاء، الأجهزة، طلبات الصيانة، المخزن.
القرارات المعتمدة: لا رقم مسلسل، لا فني، لا ملاحظات للعميل، وعنوان مطاي/بني مزار وفق القاعدة المعتمدة، والضمان بتاريخ نهاية.

هذه النسخة هي نقطة الانطلاق، وسيتم بناء الوحدات بالتتابع مع الحفاظ على العلاقات بينها.
