TWMS V4.7.1 — ملفات التعديل

ارفع الملفات التالية إلى نفس مجلد الموقع واستبدل الملفات القديمة بنفس الأسماء:

1) app-core.js
2) twms-ui.js
3) customers.html
4) requests.html
5) settings.html

أهم التعديلات:
- أرقام أوامر الشغل الجديدة: W26-8-21-1 ثم W26-8-21-2 ... مع تسلسل مستقل لكل يوم.
- مكان التنفيذ الافتراضي: منزل العميل.
- حالة الورشة الافتراضية: غير مطلوب.
- إضافة عميل سريع من شاشة أمر الشغل.
- إضافة جهاز سريع من شاشة أمر الشغل.
- إضافة قطع الغيار المستخدمة من داخل أمر الشغل مع زر تأكيد مستقل والكمية.
- تسجيل صرف القطعة وربطه بأمر الشغل وتحديث إجمالي تكلفة القطع إذا كان للصنف سعر مسجل.
- زر تم الدفع نهائيًا عند وجود فاتورة ومتَبقي.
- تتبع حالة سحب الجهاز للورشة.
- تحسين بطاقات العملاء وأزرار 360 والتعديل والحذف.
- حذف العميل يتطلب عدم وجود بيانات تشغيلية وتأكيدين.
- إعدادات مستقلة للسماح بحذف العملاء والأجهزة.
- زر حذف العملاء بلا بيانات تشغيلية من الإعدادات.
- زر مسح كل بيانات النظام مع إنشاء نسخة احتياطية قبل المسح وتأكيد كتابي.
- رفع رقم إصدار الـCore ونسخة الـUI لتجنب الكاش القديم.

مهم:
- لا تحذف app-core.js القديم قبل الاحتفاظ بنسخة منه.
- بعد الرفع افتح الموقع واعمل تحديث للصفحة.
- إذا ظهر تصميم قديم، أغلق الصفحة وافتحها مرة أخرى لأن ملفات الـCSS/JS لها نسخة جديدة في روابط التحميل.
