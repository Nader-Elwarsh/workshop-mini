# نظام الورشة المصغر

نسخة مستقلة عن المشروع القديم.

## الوحدات
- العملاء
- الأجهزة
- طلبات الصيانة
- المخزن

## القرارات المعتمدة
- العميل: اسم + تليفون + عنوان.
- المنطقة: مطاي أو بني مزار.
- عند اختيار مطاي تظهر القرية.
- عند اختيار بني مزار لا توجد قائمة قرى ويُكتب العنوان يدويًا.
- لا توجد ملاحظات للعميل.
- لا يوجد رقم مسلسل للجهاز.
- لا توجد خانة فني في طلب الصيانة.
- الضمان يعتمد على تاريخ نهاية محدد كتذكير بموعد الانتهاء.
- الربط الأساسي: العميل ← الجهاز ← طلبات الصيانة.
