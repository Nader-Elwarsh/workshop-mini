# نظام الورشة المصغر — النسخة النهائية المعتمدة

أربع وحدات متصلة ومنفصلة: العملاء، الأجهزة، أوامر الشغل، المخزن.

## العلاقات
العميل ← عناوين ← أجهزة ← أوامر شغل ← قطع غيار ← حركات المخزن.

## العملاء
اسم، تليفون، عنوان أساسي، مركز قابل للإدارة، قرية قابلة للإدارة، شارع/علامة مميزة اختيارية، عنوان إضافي اختياري. حفظ العميل يفتح ملف 360°.

## الأجهزة
النوع والتصنيف والماركة قابلة للإدارة من الإعدادات. الجهاز مرتبط بعميل وعنوان، بدون رقم مسلسل. الصور تُحفظ محليًا داخل بيانات المتصفح وتظهر في ملف الجهاز.

## أوامر الشغل
مصنعية + قطع غيار = إجمالي. العربون اختياري، والمتبقي يظهر عند وجود عربون. قطع الغيار مرتبطة بالمخزن والحساب. الحالة مكتمل لا تعني إغلاقًا نهائيًا؛ الإغلاق يحتاج تأكيدًا، وبعده لا يسمح بالتعديل. لا يوجد ضمان.

## المخزن
القطعة لها اسم وكود وتصنيف قابل للإدارة ومكان في المخزن وكمية وحد أدنى وأسعار وصورة. صرف القطع من أمر الشغل مرتبط بالحساب وتكلفة الشراء.

## الإحصائيات
ملخص رئيسي + كشف حساب شهري: المصنعية، مبيعات القطع، تكلفة القطع، الإيراد، العربون، المتبقي، المكسب، وعدد الأوامر.

## ملاحظة تقنية
هذه النسخة Front-end تجريبية تستخدم LocalStorage. الصور تحفظ كبيانات داخل المتصفح. عند نقلها إلى قاعدة بيانات/استضافة فعلية، تُحافظ على نفس نموذج العلاقات والواجهات.

## آخر تحسينات هذه النسخة
- إضافة قطعة غيار من ملف أمر الشغل مباشرة مع زر "تأكيد إضافة القطعة"؛ عند التأكيد تُخصم الكمية من المخزن ويُعاد حساب قطع الغيار والإجمالي والمتبقي وتكلفة القطع فورًا.
- يمكن تنفيذ الإضافة ما دام الأمر غير مغلق نهائيًا، حتى لو كانت حالته "مكتمل".
- رقم أمر الشغل أصبح بصيغة `W26-8-20-1`، ويتم ترتيب أرقام نفس اليوم تلقائيًا، مع ترحيل الأرقام القديمة للصيغة الجديدة.
- تم ضغط ملف أمر الشغل في واجهة واحدة وتقليل المساحات والأزرار والجداول.
- ضغط صور الأجهزة والقطع قبل التخزين مع معالجة امتلاء مساحة LocalStorage بدل فشل الحفظ بصمت.

## إضافة الكيانات من داخل أي مسار
يمكن إنشاء العميل أو الجهاز أثناء إنشاء أمر الشغل دون مغادرة الشاشة. بعد الحفظ يتم إنشاء الملف وربطه تلقائيًا بالأمر. ومن صفحة الأجهزة يمكن إنشاء عميل سريع، ومن ملف العميل يمكن إنشاء جهاز أو أمر شغل، ومن ملف الجهاز يمكن إنشاء أمر شغل.
