# نظام الورشة المصغر — نسخة 360°

نسخة مستقلة عن المشروع القديم.

## ما تم بناؤه
- العميل: بيانات أساسية بدون ملاحظات.
- العنوان: مطاي أو بني مزار، مع قرى مطاي فقط.
- حفظ العميل يفتح ملف العميل 360° مباشرة.
- ملف العميل 360° يعرض بياناته وأجهزته وطلبات الصيانة وروابط الإضافة.
- الجهاز مرتبط بالعميل وبدون رقم مسلسل.
- حفظ الجهاز يفتح ملف الجهاز 360°.
- طلب الصيانة مرتبط بالعميل والجهاز وبدون فني.
- حفظ طلب الصيانة يفتح ملف الطلب 360°.
- الضمان يعتمد على تاريخ نهاية محدد.
- المخزن له ملف 360° لكل قطعة.
- كل الملفات في جذر المشروع، بدون مجلدات داخلية.

## ملاحظة
هذه نسخة تشغيلية أولية تعتمد على LocalStorage داخل المتصفح. عند الانتقال لقاعدة بيانات حقيقية سيتم الحفاظ على نفس العلاقات وواجهات الملفات 360°.
